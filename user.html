Що таке симетричне шифрування?

Симетричне шифрування — це метод криптографічного захисту інформації, при якому для шифрування та розшифрування використовується один і той самий секретний ключ.

Під час шифрування початкові дані перетворюються на зашифрований текст. Для отримання початкової інформації необхідно використати відповідний ключ.

Алгоритм AES-GCM

AES-GCM — це сучасний режим симетричного шифрування, який забезпечує конфіденційність і перевірку цілісності даних. Він використовує секретний ключ та випадковий одноразовий вектор ініціалізації (IV).

  • Можливість використання для великих обсягів інформації.
  • Перевірка цілісності даних у режимі AES-GCM.
